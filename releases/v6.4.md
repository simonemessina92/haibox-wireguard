# HAIBOX WireGuard v6.4 — Golden

Version 6.4 extends the tested v6.3 networking baseline with operational diagnostics, clearer live monitoring and a streamlined Web UI first-login workflow.

## Highlights

- Exact build identity in the Web UI, including release channel, installed-script SHA-256, uptime, operating system, kernel and last Apply time.
- Downloadable sanitized support bundle for remote troubleshooting without private keys, credentials, password hashes, cookies or TLS private keys.
- Service-aware LAN monitoring for the HAIBOX router, StreamHub, HSG/HMG, Makito X4E, Windows Orchestrator and Proxmox.
- Full-width Connected Peers and LAN Devices panels for clearer service details.
- Automatic Web UI setup on HTTPS TCP 65000.
- Fresh installations start with `admin` / `password` and require an immediate password replacement before the dashboard is accessible.
- Credential changes are available from the Web UI and require the current password.
- CLI credential recovery resets the Web UI to its first-login state.
- Existing Web UI credentials are preserved during upgrades.

## Compatibility and safety

- WireGuard, routing, NAT, DNAT, hairpin DNAT, firewall persistence and Remote VPN Client behavior remain based on the physically tested v6.3 Golden implementation.
- The release was validated on the Amsterdam VPS test environment before promotion.
