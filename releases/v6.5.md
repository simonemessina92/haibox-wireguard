# HAIBOX WireGuard v6.5 — Golden

Version 6.5 delivers a compact operational control panel and safer day-to-day management while preserving the tested WireGuard, routing, NAT, DNAT and hairpin architecture of v6.4.

## Highlights

- Full-width Overview designed for Full HD operation, with the HAIBOX logo, essential build/network information and direct Public Services shortcuts.
- Live WireGuard peer state and HAIBOX LAN reachability with concise handshake and ICMP RTT information.
- Live 60-second RX/TX graph and per-device traffic accounting for Router, StreamHub, HSG/HMG, Makito X4E, Windows Orchestrator, Proxmox and other VPN traffic.
- RX and TX are presented from the HAIBOX/device perspective.
- Separate Configuration and VPN Profiles workspaces with compact, expandable client configuration cards.
- Expandable Port Redirects summary for HTTPS, SSH, RTMP, router and Proxmox mappings.
- Proxmox TCP 8006 is always published when the HAIBOX tunnel configuration is applied.
- Clearer configuration validation and Apply error messages.
- Transient action notifications integrated into the header and automatically dismissed after 10 seconds.

## Reliability fixes

- Apply, Test, System Health and Remote Client actions use POST/Redirect/GET. Refreshing the browser cannot replay Apply, restart WireGuard or repeat another state-changing operation.
- Web UI refresh keeps the authenticated session active; Logout remains explicit.
- Dashboard and Network Statistics polling run only while Overview is active and the page is visible.
- Network monitoring is read-only and does not reconfigure or restart the VPN.

## Validation

The release was validated on the Amsterdam HAIBOX test bench with:

- an active HAIBOX router tunnel;
- live StreamHub traffic;
- repeated Web UI refreshes without stream interruption;
- correct HAIBOX-side RX/TX direction;
- Router, StreamHub, HSG/HMG, Makito X4E, Windows Orchestrator and Proxmox monitoring;
- Remote VPN Client creation and automatic router reconnection;
- Configuration, VPN profile, System Health and support-bundle workflows.

Creating or refreshing the optional Remote VPN Client restarts `wg0` to load the peer. The HAIBOX router reconnects automatically; a brief tunnel interruption during that deliberate operation is expected.

## Compatibility and safety

- Existing WireGuard keys, Web UI credentials and saved configuration are preserved during upgrades.
- The support bundle excludes private WireGuard keys, Web UI credentials and password hashes, TLS private keys, cookies, sessions and downloadable client configurations.
- The v6.4 Golden networking model and rollback protections remain intact.
