# v6.6 Golden

This release adds browser-guided first setup and several day-to-day controls to the v6.5 WireGuard deployment.

## Changes

- After the initial password change, the wizard sets the router LAN, applies and saves the VPS configuration, then presents the router WireGuard profile. It checks active router reachability before opening Overview.
- Router and optional Remote VPN Client profiles can be copied, downloaded as `.conf` or shown as QR codes during setup and later in VPN Profiles.
- Configuration adds DMZ for otherwise unclaimed ports and a Domain field for Public Services links. The Domain field does not set up DNS or change VPN endpoints.
- Apply skips unnecessary WireGuard restarts when the running configuration is already correct. Existing profiles and keys are retained.
- Overview shows the latest four minutes of traffic. A bounded sampler on the VPS runs while a Web UI session exists, so returning to a backgrounded browser tab restores the full window. Samples are kept in RAM and cleared when the last session logs out.
- The setup cards keep their navigation in place; long profile details scroll inside the card.

An upgrade from v6.5 keeps saved configuration and Web UI credentials. The wizard appears only on installations without an applied configuration.

## Validation

Simone tested v6.6 development builds on the Amsterdam VPS with the HAIBOX router, live streaming and the Web UI. He confirmed the wizard, configuration changes and four-minute graph, including its behavior after leaving Chrome on another tab and stopping the stream. The 6.6 Golden was approved on 2026-09-28.
