# v6.8 Golden

`--reset-webui-credentials` now works from the command line. If the Web UI password is lost, run the script with this option to restore `admin` / `password`; a new password is required at the next login. Menu option 9 does the same and was already working.

The option was handled by the script but rejected as unknown since v6.4. WireGuard, routing, port forwarding and the Web UI are unchanged from v6.7.

Upgrading keeps the saved configuration and Web UI credentials.
